# Contexto
Trabalho final do curso de MBA de Engenharia de Software na FIAP.

## Tema
Produzir uma POC para um produto que deverá solucionar uma dificuldade em laboratórios de análise de imagens, mais especificamente exames de macroscopia. Geralmente são examinadas peças anatômicas e cortes histológicos. De onde se deve extrair informações básicas como tamanho, peso, coloração, etc.

## Dificuldade
Atualmente, a extração dessas informações é feita manualmente, o que demanda tempo e pode gerar erros.

## Solução
- Para a POC, desenvolver uma aplicação que permita o upload de imagens e a extração automática das informações desejadas.
- Posteriormente, a aplicação deverá ter uma interface web amigável e intuitiva. Intenção é rodar tudo na AWS utilizando serverless, S3, cloudfront e terraform.

## Requisitos
- Upload de imagens
- Extração automática das informações desejadas
- Interface web amigável e intuitiva
